{# The header every admin surface carries, naming both surfaces the session can reach. The current one is identified rather than linked, so the header reads as a position rather than as an undifferentiated pair of links. The paths are literals. `launch` cannot import `access`'s `PAGE_PATH`, and `access` already writes `launch`'s path as a literal (`ADMIN_HOME_PATH`), so one literal pair in one shared partial is strictly fewer than the two in two modules that stood here before. The outbound link from the playbook surfaces is un-boosted, for the reason `page.html`'s Add step control already records: `hx-boost` is inherited from ``, so htmx would swap the roster page into this page's body, discard that page's own body attributes and leave a roster page that cannot post. #}
